## Ordem de trabalho

1. **Hoje:** responder as conversas abertas (DM é cliente pedindo atendimento).
2. **Piloto:** escolher 1 cliente e fazer o diagnóstico completo:
   `/ig-profile` → preencher `voice.md` → `/ig-audit` → `/ig-viral`.
3. **Rotina semanal do piloto:** `/ig-plan` na segunda, `/ig-reel` / `/ig-carousel` / `/ig-caption`
   para produzir, `/ig-story` e `/ig-reply` todo dia.
4. **Depois de 2 semanas:** repetir o diagnóstico nos outros, 2 ou 3 por semana.

Cada cliente fica com: `voice.md`, `diagnostico.md`, `plano-AAAA-MM-DD.md` e `posts/`.
